# Python Weather App

A simple, beginner-friendly Python application that fetches and displays current weather information for any city using a public weather API.

# Features

- 🌍 **Real-time Weather Data** – Fetches current weather conditions for any city worldwide.
- 🏙️ **City-based Lookup** – Enter a city name to get localized weather info.
- 🌡️ **Key Weather Metrics** – Displays temperature, humidity and weather description.
- 💻 **Simple CLI Interface** – Clean and easy-to-use command-line interface; no complex setup required.
- 🔌 **API Integration** – Demonstrates how to call REST APIs and parse JSON responses in Python.
- 🧪 **Beginner Friendly** – Well-structured code suitable for learning HTTP requests, environment variables, and error handling.

#  Set-up

 ## On device
- Install python on your device.
- Install a code-editor on your device.

## On code editor 
- Install python extension.
- On terminal:
    ```bash
   pip install requests
   ```

## For API_KEY
- Create a account on **[open weather map](https://openweathermap.org/)**.
- Copy your API_KEY and paste it in the **[python-weather-app](https://github.com/Z4R1Q/python-projects/blob/main/python-weather-app/python-weather-app.py)** code.
