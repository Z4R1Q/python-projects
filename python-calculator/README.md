# Python calculator
A simple python tkinder calculator for basic mathematic operation.

# Feature
- Clean and simple UI.
- Mathematic operation like addition, subtraction, multiplication, and division.

# Tech
- Python.
- Tkinder.

# Set up
## On devices
- Install python on your device.
- Install a code-editor.
## On code-editor
- Install python extension on your code-editor.
